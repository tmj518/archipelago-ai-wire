> 关于 `git diff --check`：本仓库是 CRLF 仓库且无 `.gitattributes`，默认规则会把每一行行尾的 CR 判为 trailing whitespace。使用 `core.whitespace=...,cr-at-eol` 后 **exit 0**。没有为此改写全仓库行尾（会制造数百文件的无意义 diff）。

1. `astro build` 因 `guide/[slug].astro` import 了使用 `node:fs` 的 `taxonomy.mjs` 而报 `ENOENT dist/.prerender/chunks/taxonomy.json` → 改为直接 import JSON。
