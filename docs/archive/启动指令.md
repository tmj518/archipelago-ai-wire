# 启动指令（每天用这一份）

> **这是唯一的入口。** 每天定时任务读的就是它，你手动启动也发它。
>
> 建立于 2026-10-08。**下面的命令可直接复制。**

---

## 一、一句话启动（复制这个）

```
读 daily-task.txt 并按它执行。先做第二步：读完全部七份必读文件（清单在 daily-task.txt 第二步的表里），
再开始干活。读完就开始，不要问我，不要等我确认。
```

**就这一句。** 其余细节全在 `daily-task.txt` 里，**因为那是智能体实际执行的那份**。

---

## 二、或者用命令（等价，但会先跑体检）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\run-daily.ps1
```

**它会按这个顺序做五步**：

| 步 | 做什么 | 在哪运行 |
| --- | --- | --- |
| **1** | preflight（含 `required docs`、`doc encoding`、`tools parse`） | 沙箱外 |
| **2** | 把 `daily-task.txt` 喂给智能体执行 | 沙箱内 |
| **3** | 本地 commit | 沙箱内 |
| **4** | 生产构建 + 推送 | 沙箱外 |
| **5** | 等部署 + 核实线上 | 沙箱外 |

**只体检、不干活**（想先看环境是否健康）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\run-daily.ps1 -PreflightOnly
```

## 三、定时任务已注册（不用你管）

```
任务名   LandedMath-Daily
时间     每天 08:10
动作     tools\run-daily.ps1
```

**查它**：

```powershell
schtasks /query /tn LandedMath-Daily /v /fo LIST | Select-String "TaskName|Last Run|Last Result|Next Run|Status"
```

**健康的样子**：`Last Result: 0`（0 = 成功；**2 = 包装脚本的 FATAL，那是失败**）。

## 六、每天结束时必须留下三样东西

**这是"越做越智能"的机制，不留下就等于这轮白干：**

| # | 留下什么 | 落在哪 |
| --- | --- | --- |
| **1** | **今天学到的一条可复用规则** | `经验与踩坑记录.md` |
| **2** | **如果规则变了，改在明处（注明日期与理由）** | `初心与目标.md` / `指令_完整版.md` / `daily-task.txt` |
| **3** | **如果发现工具缺陷，修它** | `tools/` 里的脚本 |

> **★ 判据**：**如果一条经验只活在某轮对话里，那它就是白学了。**
