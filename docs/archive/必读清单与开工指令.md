## 三、★★ 开工指令（可直接复制）

**下面这段就是"每天你给我的完整指令"。`daily-task.txt` 里是它的展开版。**

```
本工作区是 Landed Math（landedmath.com），英文内容站，把中国一手官方数字变成外国买家发票上的钱。
你由定时任务启动。这一份就是完整指令，读完就开始干活，不需要再问。

── 第 0 步：读完这七份，缺一份不许开工 ──

全文读完（4 份）：
  1. 信源清单.md            → 选来源：23 个可达入口 + 来源类型→题型索引
  2. 初心与目标.md          → 裁决标准：★ 完成度 > 搜索意图 > 有价值，字数只是结果
  3. 经验与踩坑记录.md      → 不重复踩坑：7 次编码坑 + 工具陷阱 + 对标结论

只读指定章节（3 份）：
  5. 项目规范_英文内容站_v1.4.md  → 只读 §5 写作模板 V6.2
  6. 进度日志.md                 → 只读最后三节（那份文件 200 KB，绝不全文读）
  7. 对标学习10条.md             → 只读今天要执行的那一条

不要读：v1.0 / v1.2 规范（已被取代）、docs/archive/下一步_2026-10-06_已过时.md（已过时）、README.md（不是规则）

── 第 1 步：确认环境 ──
node tools/preflight.mjs
看除「astro build」「git remote」「python」之外的项（那三项是沙箱产物，不是你造成的）。
required docs、doc encoding、qa-check、tools parse、review-dates 若红，那是真问题，写进报告。

── 第 2 步：复查 ──
取 reviewBy 最近到期的一篇 → 对照它引用的一手来源重读（读原文，不读二手转述）
  有实质变化 → 公开更正（写进 revisions 与 updatedDate）

从 信源清单.md 选来源 → 优先查省级与目的市场（信息增量最高）

  1. 内容完整度：搜这个题的人需要的每个问题都回答了吗？缺哪个？

   必须落到 初心与目标.md / 指令_完整版.md / daily-task.txt / 经验与踩坑记录.md 之一，

3. ★ 三关自查的答案（完整度 / 搜索意图 / 价值）

5. 还哪些没做完，按等级（卡凭据的 / 我能独立做的 / 等用户决定的）
6. 需要用户给什么
7. 成本
8. 本周进度一行：本周净新增 X/15 篇 · 各栏目 N/N/N/N/N 篇
```

## 四、这份清单怎么被强制执行

**三层，缺一层就有漏洞：**

| 层 | 机制 | 防什么 |
| --- | --- | --- |
| **1. 写进指令** | `daily-task.txt` 第二步就是这份清单 | 智能体知道要读什么 |
| **2. preflight 检查** | `required docs`（文件存在 + 最小字节数）· `doc encoding`（有效 UTF-8，排除代码块里的引用） | 文件缺失、被截断、被弄坏 |
| **3. 报告强制项** | 报告的 0 / 3 / 4 项分别是净新增、三关自查、对标学习 | 跳过步骤会显现在报告里 |

**实测**：

```
[ ok ] required docs        4 present — sources, goals, lessons, benchmarks
[ ok ] doc encoding         30 documents are valid UTF-8, ignoring quoted examples
```

> **★ 而第 1 级那四份的字节下限是刻意设的**：
> `信源清单.md` ≥4 KB · `初心与目标.md` ≥2 KB · `经验与踩坑记录.md` ≥4 KB · `对标学习10条.md` ≥3 KB。
> **一个被清空的文件和一个不存在的文件一样危险，而 `existsSync` 查不出前者。**

## 五、已知的缺口（诚实列出）

| 缺口 | 影响 |
| --- | --- |
| **闸门判不了"完成度"和"搜索意图"** | 那两条只能靠报告里的三关自查强制，**而自查是自觉性的**——这是当前最大的软肋 |
| **没有每日必读的机器验证** | preflight 查文件存在，**但查不了"智能体真的读完了"**。只能靠报告里的 0/3/4 项间接判断 |
| **`进度日志.md` 有 200 KB 且在增长** | 只读最后三节是权宜。**到 500 KB 时该做归档**（把旧章节移到 `进度日志_归档.md`） |
| **对标学习第 4 条"至少执行一条机制"无法机器验证** | 同上，靠报告 |
