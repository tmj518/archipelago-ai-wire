# archive/

Files kept because they record something real, removed from the working set because they conflict
with the current source of truth.

## 启动指令.md and 必读清单与开工指令.md — archived 2026-10-12

Both were instruction documents, both dated 2026-10-08, and both overlapped `指令_完整版.md`
without being identical to it. The director's v1.5 decision is that the master instruction has one
source: `指令_完整版.md`.

The reason to archive rather than delete is that two conflicting instructions are more dangerous
than one stale instruction. A reader who has two versions picks the one that suits them, and the
disagreement never surfaces. One version with the stale parts marked in place does surface.

Their content is preserved here unmodified. What they contributed that the master file lacked — the
tiered reading list and the copy-paste startup block — is referenced from `daily-task.txt`, which is
where the daily routine is actually read from.
