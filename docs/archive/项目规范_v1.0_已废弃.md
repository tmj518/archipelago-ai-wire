# 跨境英文内容站 · 项目规范 v1.0

> 创建时间：2026-09-29
> 项目：China Cross-border Insider（暂定名）
> 技术栈：Astro + GitHub + Cloudflare Pages（无服务器）
> 目标：英文深度内容站，Google SEO，长尾打法，12个月慢生意

---

## 一、网站定位

- **目标受众**：海外中小卖家、做中国采购的老外、做TikTok/Amazon的从业者
- **内容方向**：中国跨境电商/贸易/供应链的深度解读
- **人设**：Cross-border Veteran（10年跨境老兵，做过Amazon/Temu/TikTok/D2C）
- **语气**：犀利、直接、有态度，像跟同行聊天，不官腔
- **差异化**：不是新闻搬运，是成本测算+行动清单+真实经验

## 二、技术架构

```
豆包定时任务（每天/每周）
  → 写英文文章（Markdown）
  → AI配图
  → 飞书文档给用户审稿
  → 用户说"发"
  → git push到GitHub
  → Cloudflare Pages自动构建部署
  → 自动提交GSC Indexing API
  → 每周拉GSC数据 → 选下周选题
```

- 不跑在用户本地电脑，不依赖用户开机
- 不需要服务器、Docker、n8n、Dify
- CF Pages免费额度：500次构建/月、无限带宽、文章数不限

## 四、内容生产SOP（AI初稿+人工深度）

### 4.1 每篇文章必须有的"人工痕迹"（模板写死）

| 元素 | 要求 | 来源 |
|------|------|------|
| 精确数字 | 至少5个，带数值+单位+时间+来源 | 海关总署/商务部/统计局/CCTV |
| 成本测算 | 至少1个，具体到FOB价×税率×柜量 | 我算 |
| 第一人称经验 | "I've been selling on Amazon since 20XX..." | 用户提供真实经历，我润色 |
| 明确观点 | 不要和事佬，要有"Don't do X. Do Y." | 我基于行业判断 |
| 反常识点 | "Most sellers think X, but actually Y" | 我写，用户审 |
| 分人群建议 | 新卖家/品牌卖家/套利卖家分别怎么办 | 我写 |

### 4.2 写作模板V6.1（每篇固定结构）

1. **Hook（100字）**：抛出反常识问题
2. **What happened（400字）**：精确数字+政策原文
3. **Why now（400字）**：联系前后政策脉络（追溯2-3年）
4. **So what（500字）**：我的判断+成本测算+反常识点
5. **For you（400字）**：分人群建议+行动清单+时间窗口
6. **Data point（200字）**：一个关键数字收尾

目标字数：1500-2500字。

### 4.3 发布前质检清单（15项）

- [ ] 至少5个精确数字（数值+单位+时间+来源）
- [ ] 至少1个成本测算（FOB×税率×柜量）
- [ ] 至少1个反常识观点
- [ ] 至少3个分人群建议
- [ ] 没有"may/might/possibly/perhaps"这种模糊词
- [ ] 信源都是官方（商务部/海关/统计局/CCTV/新华社）
- [ ] 字数1500+
- [ ] 有明确观点，不是和事佬
- [ ] 有第一人称经验段落
- [ ] 有具体行动清单（谁、什么时候、做什么）
- [ ] 有政策时间线（2024→2025→2026）
- [ ] 没有URL网址出现在正文（只标信源名称）
- [ ] 英文地道，没有中式英语
- [ ] 有about页链接和作者卡片
- [ ] 有privacy policy和disclaimer

### 4.4 人工审稿环节

我写完后发到飞书文档：
- 用户看观点对不对（10年老炮判断）
- 用户补真实经历（"我2019年遇到过..."）
- 用户看英文够不够地道
- 用户说"发"或"改XXX"

## 五、选题系统

### 5.1 选题表字段

| 字段 | 说明 |
|------|------|
| 关键词 | 长尾词，如"TikTok Shop China seller requirements 2026" |
| 搜索意图 | 信息型/交易型/对比型 |
| 目标字数 | 1500-2500字 |
| 信源清单 | 必须用哪几个官方源 |
| 独家角度 | 这篇跟别人有什么不同 |
| 状态 | 待写/写作中/待审/已发 |

### 5.2 长尾选题来源（每周自动）

1. Google Trends上升词
2. Reddit r/AmazonSeller、r/ecommerce老外问什么
3. Twitter/X跨境从业者讨论
4. "how to"、"what is"、"vs"长尾问题
5. GSC回流数据：哪些词有曝光没点击

**不抢大词（如"China sourcing"），做长尾深度。一年200篇。**

## 六、需要用户提供的材料

- [ ] 作者真实信息：笔名/名字、做跨境几年、主要平台/品类、真实照片或头像
- [ ] 真实案例2-3个：踩过的坑、赚过的钱、做对的决策

- [ ] LinkedIn/Twitter（可选）

## 七、内容红线

- 不写敏感政治、民族、领土话题
- 不编造数据，不确定的标"待核实"
- 不冒充官方机构
- 视频传YouTube/B站嵌入，不放进Git仓库
- 每篇文章底部："Independent analysis, not financial or legal advice"
