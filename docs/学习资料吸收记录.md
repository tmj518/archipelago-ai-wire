## 资料 1：《谷歌官方SEO学习总结.md》

（已作为 SEO 落地清单并入 PROJECT_SPEC 第九章，此处为要点存档）

### 硬性技术要求（仅 3 条）
1. Googlebot 可达
2. 返回 HTTP 200
3. 内容可索引且不违反 spam 政策

### 关键纪律
- **robots.txt 不能阻止收录**：付费简报页要防止被收录，必须用 `noindex`（且允许抓取），不是靠 robots 屏蔽。
- **canonical / sitemap / BreadcrumbList 是 hint 而非必须**；Breadcrumb 的 `itemListElement` 是唯一硬性 required 字段集。
- **E-E-A-T 非排名因素，但 trust 最重要**：禁止伪造作者（AI 头像/假名/假资历=欺骗）。→ 本项目用**机构署名**（如 "Desk"）规避。
- **scaled content abuse** = 很多页 + 无价值增量。AI「翻译+表格」型内容高风险。→ 本项目护城河是**信息增量 + 一次文献直读**，不是产量。
- **llms.txt / AEO / GEO 花招不用做**（Google 明确）。
- **AI 内容本身不违规**，但 title/meta/JSON-LD/alt 必须人工核实。
- **单一站不需要 hreflang**；多语种子目录站需要成对自指 hreflang。
- **时政+经济解读属 YMYL 题材**：需更强 E-E-A-T + 免责声明。→ PROJECT_SPEC 已含「不构成投资建议」强制标注。
- sitemap 500 页以下且内链完整 → 官方判「不需要但建议」；`priority/changefreq` 被忽略，`lastmod` 仅持续可验证才用。
- 首屏用原生 `<a href>`；官网外链 citing sources 有助信任。
- **CWV 阈值**：LCP ≤2.5s / INP ≤200ms / CLS ≤0.1（p75，移动+桌面分开）。

## 资料 2：《项目路线图_五年_0到100万UV.md》

（旧定位五年规划，含附录 A 硬目标修订。以下拆分可迁移与不可迁移。）

### 【可直接迁移的方法论】

#### ① 多语言 = 每个语种独立选题，不是翻译
> 翻译过来的内容在目标语种没有搜索需求匹配，等于把英文选题硬塞进另一个市场。
- **本项目映射**：四国独立域名各自独立选题（马站东盟经贸、印尼产业、拉美西语、巴西葡语），完全吻合——项目文档已定「一国一独立域名，本地化改写非机翻」。

#### ② 播客：通过一个 RSS feed 一次分发，不逐个平台上传
> Spotify / Apple Podcasts / YouTube Music / Amazon Music 通过一个 RSS feed 分发。
- **本项目映射**：PROJECT_SPEC 目录有 `/podcast/`。落地时生成统一播客 RSS，一次提交各平台。
- 诚实提醒：AI 合成语音在播客口碑不佳 → 定位为「文章朗读」而非「播客节目」，或用真实人声。

#### ③ 视频回写文章 = 停留时长上升 + 双向导流 + 独立 SERP 占位
- 文章嵌 `youtube_id` → `YouTube.astro` 组件（`youtube-nocookie.com` + `loading="lazy"`）。
- 视频**不进 Git 仓库**，只存 ID。
- 纯 AI 合成视频对 E-E-A-T 负分 → 需真实录屏或人声。
- **本项目映射**：11 智能体中「智能体7 多载体衍生创作」产播客稿 + YouTube 脚本；落地时补齐 youtube_id 字段与回写机制。

#### ④ KPI 纪律：主指标 = 订阅数 > GSC 曝光量 > 被 AI 引用次数
> 明确不以访问量为主指标；AI Overview 使传统结果 CTR 下降约 61%。
- **本项目映射**：付费订阅是核心变现，KPI 主指标必须是订阅转化，不是 UV。

#### ⑤ 风险登记册（R1-R7）直接复用
| 旧风险 | 本项目映射 |
|---|---|
| AI Overviews 压缩点击（CTR −61%） | 同样成立 → 对冲：邮件列表 + 成本测算/「AI 答不好」的深度推演内容 |
| Google 核心更新 | 不依赖单一渠道；邮件列表不可被剥夺 |
| 规模化内容滥用 | 信息增量闸门 + 单日上限 + 站内查重 |
| 多语言执行失败 | 每语种独立选题；hreflang 成对 |
| 视频/播客产线拖垮主产线 | 排到 Y2；Y1 只做验证 |
| 单点依赖 | 规范文档化 + 流水线可重放 |
| 数据准确性事故 | 五元组 + 三道闸门 + 更正机制 |

#### ⑥ 回流机制（GSC 数据 → 反馈优化）
```
GSC query → 有曝光无点击 → 改 title/description
          → 有排名点击低 → 改 AI Summary（意图不匹配）
          → 30 天零曝光   → 重跑闸门：通过=选题问题退回池；失败=闸门漏检改规则
          → 未瞄准新 query → 进下周选题池
```
- **本项目映射**：对应「智能体11 数据分析&闭环优化」的选题权重调整，落地时建固定每周回流。

### 【不可迁移（旧定位特有）】
- 具体 UV 数学（单篇 100 次/月、语种流量系数 ES≈0.6×/PT≈0.45×）——基于「贸易数据→到岸成本」的搜索需求密度，时政站需按自身 GSC 重算。
- 内容节奏「每周 5 篇每栏目 1 篇」——本项目一期按项目文档定「每日 1~2 篇小批量测试」。
- 语种顺序（EN→ES→PT→AR）——本项目定死四国顺序：马→印尼→西语→葡语。
