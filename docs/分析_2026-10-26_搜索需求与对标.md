## 四、两个对标站：它们不是我们的竞品

| | Sinocism | ChinaTalk | landedmath |
|---|---|---|---|
| 形态 | Substack 日报/周报 | Substack + 播客 + 访谈 | 静态站 + 数据页 |
| 订阅 | **428,000** | **82,000** | 0 |
| 内容 | 政策观察、链接+点评 | 深度访谈、科技政策 | 数字+来源+计算 |
| 护城河 | 作者本人 + 十年声誉 | 作者本人 + 人脉 | **可核验的数字** |
| 变现 | 订阅费 | 订阅费 + 赞助 | （未定） |
| 搜索依赖 | 极低（品牌词为主） | 极低 | **100%** |

**关键判断：把这两个当"内容对标"会走错方向。**

它们卖的是"我替你读完今天的东西"，靠的是作者观点和人脉；我们卖的是"这个东西到底多少钱"，靠的是可核验。照着它们的形态做（观点、访谈、newsletter 文风），等于放弃我们唯一的不同点。

### 但有两件事必须抄

**1. 收件箱。** 它们的读者不是搜出来的，是订出来的。428k 和 82k 的邮件列表意味着每次发文都有基础流量；我们的站现在没有任何订阅入口，发一篇就是发一篇。

**2. 一个固定节奏。** 两者都是"每周固定时间到你的邮箱"。我们每天发一篇但读者不知道"什么时候来能看到新东西"。

**不建议抄的：** 日报式的链接点评。那是他们的护城河（人脉+判断），不是我们的。

## 五、下一步该做的三件事（按性价比排）

### 第 1 件：把 `landed cost calculator` 从第 89 名救回来

这是全站投入产出比最高的一件事。做法：

- 专题页从"计算器入口"变成"这个词的最佳答案"：H1 直接是 `Landed Cost Calculator`，首屏给出输入框 + 一个真实算例（用现有文章里的关税数字）
- 50 篇博客的内链统一指向它（现在平均出链 2.8，其中指向计算器的很少）
- 加 `WebApplication` 结构化数据
- 标题里带上 "China"，因为那是我们的差异

### 第 2 件：选题从"部委今天发了什么"转向"外国人今天在搜什么"

90 天 27 个查询就是证据：欧盟反倾销公告这类题材，**英文搜索需求几乎不存在**。而 guide 那批（签证延期、居留许可、税务居民）是真有人搜的意图词。

建议：**A 线的选题池从贸易公告转向"在马/在华生活的成本问题"**，贸易公告降为 guide 里的引用来源。

### 第 3 件：加订阅入口（唯一能绕开 Google 的渠道）

不用做复杂系统：文章底部一个邮箱框 + 每周一封"本周的数字"摘要。这是 Sinocism 和 ChinaTalk 唯一真正值得抄的地方。

## 六、顺手修掉的一个 bug

周更审计（`seo-audit.yml`）今天连续失败两次，原因是提交步骤：

```bash
git add data/backtest.jsonl data/gsc/gaps_*.json   # 第二个 glob 匹配不到 → fatal
```

它会**在测量完成之后**才死，所以每周的回测数据被丢掉、工作流标红。已修：每个文件只在存在时才 add，判断依据改成索引。修复后重跑，绿，回测数据已提交（`7ddc629`）。

另外发现 `query-gap.mjs` 的覆盖判定有 bug：27 个查询里它报 `covered: 0`，但实际有 7 个查询对应着我们已有的页面。不影响产出，但会让"缺口"看起来比实际大。
