## 一、★ 按角色分三类，不要混为一谈

**这是最重要的一节。三类对标的用途完全不同，混起来会得出错的结论。**

| 类别 | 对标什么 | 学它的哪一部分 | 能不能学规模 |
| --- | --- | --- | --- |
| **A. 工艺标杆** | 可核验性、数据单元、引用机制 | **方法论** | ❌ 不能（机构资助） |
| **B. 生意标杆** | 谁付钱、怎么收、收多少 | **定价与产品分层** | ⚠️ 部分（它是 B2B 销售驱动） |
| **C. 成长参照** | 一人/小团队能做到多大 | **天花板与路径** | ✅ 能（同规模起点） |
| **D. 页面模板** | 具体页面怎么写 | **结构与文案** | ✅ 能（直接照抄结构） |

## 三、A. 工艺标杆：Our World in Data

| | |
| --- | --- |
| **网址** | `https://ourworldindata.org` |
| **月访问** | **约 357 万**（审计年报推算） |
| **规模** | **14 名员工** · 2025 收入 **£4,551,476** · >100,000 newsletter 订户 |
| **硬数字来源** | **GCDL 2025 审计年报**（PDF 原件已归档）· 原文 "around 168,000 page views per day, totalling more than 60 million page views over the year" |

**学它的 6 条**：

1. **每个数据单元一个可路由 URL**（它有 11 个 grapher 链接、9 个图表 URL）
2. **`citation_*` Highwire + BibTeX + 许可锚点**（7 个 `citation_*` 标签）
3. **公开方法页**
4. **版本快照**
5. **可嵌入的图表单元**
6. **负空间的使用**（它的长文 `<table>` = 0，用可路由的图替代表格）

**❌ 不学**：它的机构资助模式、14 人团队叙事。

**⚠️ 一个已失效的数字不要引用**：网上说它"接近 1 亿访客"——**源页已 301 到 `/about`**，与审计年报 60M 差 5 倍。

## 四、B. 生意标杆：Trivium China

| | |
| --- | --- |
| **网址** | `https://triviumchina.com` |
| **定价（2026-10-08 实测）** | **$18 / mo · $28 / mo · $188 / yr · $299 / yr** |
| **月访问** | 约 2.3 万（**第三方估算，置信度低**） |
| **LinkedIn** | 5,984 粉丝 · 14 名收录员工 |

**学它的 3 条**：

1. **定价公开且分档清晰**（个人 / 团队）
2. **免费日更导流 → 付费产品线**
3. **`/research/` 免费长文当获客**

**❌ 最重要的负面学习：它建了 1,177 个 `/sources/<entity>/` 信源页，全部在登录墙后。**
**抓 `/sources/nbs/` 返回的是 48 KB 登录页——那 1,177 个页面对 Google 和 AI 引擎的索引价值 = 0。**

> **它敢这么干是因为分发不靠搜索**（邮件是入口、背后有销售团队）。**这两个前提我们都不具备。**
> **→ 所以：任何动作的代价若是"把页面放到会员墙后"，就不做。**

**★ 而它的网站流量不能当基准**：邮件阅读不产生网站访问，23,001/月系统性低估其真实读者量。

## 六、D. 页面模板：这三个是**页面级**要照抄的（★ 当前缺口）

**这三个不是"对标对象"，是"页面怎么写"的模板。它们的价值在于结构可以逐项对照。**

### 6.1 `https://tldr.tech` —— **首页模板**

| 要素 | 它怎么做 |
| --- | --- |
| **H1** | **"Keep up with tech in 5 minutes"**——**承诺时间，不承诺内容** |
| **按钮** | **只有一个** |
| **首页** | **直接列出邮件内容**（不藏） |
| **每条** | **只有「标题 + 来源域 + 阅读时长」**——三个字段，没有摘要 |
| **规模** | 百万级订户（**数字待核实**） |

**★ 我们该学的**：**H1 承诺一个具体的时间成本**，而不是说"深度分析"。
**★ 我们不该学的**：**它的内容形态是策展（curation），我们是加工（analysis）**——它每条只有一个链接，我们每条是一个算式。

### 6.2 `https://the-ken.com/pricing/` —— **定价页模板**

| 要素 | 它怎么做（2026-10-08 实测） |
| --- | --- |
| **H1** | **"The only business subscription you need"** |
| **结构** | **三档 + "Comparison Chart" 功能矩阵** |
| **锚定** | 有划掉的价格（`<s>` / `<del>` / `<strike>`） |
| **标注** | 有 "MOST POPULAR" 之类的档位高亮 |
| **★ 病毒机制** | **"Gift a 1 Year Subscription for Free" / "1+1 subscription"**——订户可免费送一年给别人 |
| **功能项** | Daily Long-form Stories · Premium Newsletters · Visual Stories · Podcasts · App Access · **Partner Account Access**（两个独立 Premium 账号）· **Priority Access** |

**★ 我们该学的 3 条**：

1. **功能矩阵用划掉/高亮做锚定**，不是平铺三栏
2. **"MOST POPULAR" 标在中间那档**
3. **★ "送一年给别人"是最便宜的获客机制**——订户帮你带人，成本为零

**★ 而我们目前没有定价页**（全站零价格）。**这是缺口，也是 10 条机制里"先给后卖"的前提。**

### 6.3 `https://www.dealstreetasia.com` —— **区域商业媒体的付费形态**

| | |
| --- | --- |
| **定位** | 东南亚（PE / VC / 并购 / 创业）商业新闻 |
| **H1** | （无 h1，用导航与标题层级） |
| **价格线索** | 实测页面上出现 `$320` |

**★ 它对我们最相关的一点**：**它是"非英语母语区域的英文商业媒体"——和我们要做的事同构。**
**它证明了"区域专业信息 → 英文付费读者"这条路走得通。**
